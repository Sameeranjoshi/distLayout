1-D halo plan

48 elements, 4 PEs, radius-1 halo: which neighbor sends what

01Input: logical tensor

Each element is colored by its primary owner. Hover an element to see every PE that holds it.

02Mapping: PE grid

The region each PE holds. Striped cards are read-only replicas; the solid card along a replicated axis is the primary owner.

03Local views

Each PE's local buffer, in local coordinates.

04Layout

Decomposition + mapping, bound to existing storage.

view = bind(
    l2,
    Decomposition(Block(axis=0, parts=4)),
    Map(Grid(4), {0: 0}),
)

As an attribute (future #dist.layout)

#dist.layout<shape = [48], grid = [4], decomp = [block<axis = 0, parts = 4>], place = [0 -> g0], replicate = []>

05Generated code

What the AIR backend emits inside the herd body.

with air.herd([range(0, 48, 12)]) as h:
  @h.body
  def _(tx):
    a = air.alloc([12], f32, scope=h.private())
    air.ops.load(a, l2[tx*12 : tx*12 + 12])

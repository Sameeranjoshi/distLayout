eltwise_add_with_l2

upstream example, n=2048, tile=256: layout → air.api → MLIR

01Input: logical tensor

Each element is colored by its primary owner. Hover an element to see every PE that holds it.

02Mapping: PE grid

The region each PE holds. Striped cards are read-only replicas; the solid card along a replicated axis is the primary owner.

03Local views

Each PE's local buffer, in local coordinates.

04Layout

Decomposition + mapping, bound to existing storage.

view = bind(
    l2_a,
    Decomposition(Block(axis=0, parts=8)),
    Map(Grid(8), {0: 0}),
)

#dist.layout<shape = [2048], grid = [8], decomp = [block<axis = 0, parts = 8>], place = [0 -> g0], replicate = []>

05Generated code

What the AIR backend emits inside the herd body.

with air.herd([range(0, 2048, 256)]) as h:
  @h.body
  def _(tx):
    a = air.alloc([256], f32, scope=h.private())
    air.ops.load(a, l2_a[tx*256 : tx*256 + 256])

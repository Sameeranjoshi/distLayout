2-D block

16×32 tensor in 2×2 tiles

01Input: logical tensor

Each element is colored by its primary owner. Hover an element to see every PE that holds it.

02Mapping: PE grid

The region each PE holds. Striped cards are read-only replicas; the solid card along a replicated axis is the primary owner.

03Local views

Each PE's local buffer, in local coordinates.

04Layout

Decomposition + mapping, bound to existing storage.

view = bind(
    l2,
    Decomposition(Block(axis=0, parts=2), Block(axis=1, parts=2)),
    Map(Grid((2, 2)), {0: 0, 1: 1}),
)

As an attribute (future #dist.layout)

#dist.layout<shape = [16, 32], grid = [2, 2], decomp = [block<axis = 0, parts = 2>, block<axis = 1, parts = 2>], place = [0 -> g0, 1 -> g1], replicate = []>

05Generated code

What the AIR backend emits inside the herd body.

with air.herd([range(0, 16, 8), range(0, 32, 16)]) as h:
  @h.body
  def _(tx, ty):
    a = air.alloc([8, 16], f32, scope=h.private())
    air.ops.load(a, l2[tx*8 : tx*8 + 8, ty*16 : ty*16 + 16])
